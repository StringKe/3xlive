# Tron/Neon 赛博朋克视觉规范

## 风格定义

3X Live 的视觉语言来自 Tron Legacy + 赛博朋克的荧光美学：

- 深色背景上的高对比度霓虹几何体
- HDR + Bloom 自发光效果
- 简洁的几何形状（六边形、三角、菱形）
- 发光网格线地面（Tron 风格 Grid）
- 颜色方案以 Cyan 为主色调

## 颜色规范

### 实体颜色

| 实体     | 颜色             | 说明                      |
| -------- | ---------------- | ------------------------- |
| 本地玩家 | Cyan HDR（高亮） | 六边形，最醒目            |
| 友方玩家 | 暗 Cyan          | 六边形，降低亮度区分      |
| 敌方玩家 | Red              | 六边形                    |
| 普通怪物 | Green / Purple   | 三角或方块（id % 2）      |
| 精英怪物 | Gold HDR         | 菱形，1.3x 缩放，脉冲动画 |
| Boss     | Red HDR（高亮）  | 六边形，3x 缩放，呼吸动画 |
| 弹射体   | 高亮粒子         |                           |

### UI 颜色

| 用途     | 颜色           |
| -------- | -------------- |
| 主色调   | Cyan (#00E4FF) |
| 空槽位   | 深灰           |
| 面板背景 | 半透明深色     |
| HP 条    | 红色           |
| XP 条    | 黄色           |
| 能量条   | 青色           |

### 背景

- 深蓝/近黑背景
- ClearColor 极深色
- 网格地面 shader 绘制 Tron 风格发光线条

## 渲染技术

- Bevy HDR 摄像机 + Bloom（intensity=0.3）
- Mesh2d 几何体（非精灵图片）
- 实体颜色使用 HDR 值（超过 1.0）触发 Bloom
- 伤害数字：Text2d 上浮 + 淡出
- 死亡效果：碎片散射
- 掉落物：旋转 + 呼吸缩放（相位错开避免同步闪烁）

## 设计原则

- 所有视觉元素都是几何图形，不使用位图精灵
- 实体大小和发光强度传递信息（越强的敌人越大越亮）
- 动画简洁：脉冲、呼吸、旋转，不使用复杂骨骼动画
- UI 风格与游戏世界一致：直线、锐角、霓虹色、无圆角装饰

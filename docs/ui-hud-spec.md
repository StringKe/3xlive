# 3X Live HUD UI 设计指导

## 一、视觉风格

**主题**：Tron/Neon 赛博朋克
**字体**：Noto Sans 系列（en/zh-CN/ja/ko）

**配色**：
| 用途 | 颜色 |
|------|------|
| 主色调 | 青色 `#00E4FF` |
| 背景 | 深蓝黑 `#0A0F1A` |
| 面板背景 | 半透明深蓝 |
| 生命条 | 绿色 `#00FF88` |
| 经验条 | 金色 `#FFDD00` |
| 能量条 | 青色 `#00E4FF` |
| 文字主色 | 白色 |
| 文字次要 | 灰蓝 |

## 三、组件说明

### 3.1 调试信息

- **位置**：左上角
- **内容**：FPS 等状态
- **样式**：纯文字，绿色，半透明背景，无边框

### 3.2 通知飘字

- **位置**：顶部居中
- **内容**：Level Up、新武器解锁等系统公告
- **样式**：金色或绿色文字，居中显示

### 3.3 小地图

- **位置**：底部右侧
- **内容**：玩家位置（青点）、怪物位置（红点）
- **样式**：深色背景，青色边框，简洁圆点

### 3.4 背包 + 编辑器（底部中央，统一网格布局）

**布局**：左右水平分割，统一网格定位

**左侧 - 武器信息**：

- 武器图标（六边形）
- 武器名称 + 品质
- 属性（伤害/射速/射程）
- 生命条、能量条、经验条
- Program 槽位（根据 Disc 品质自动布局）

**Program 槽位布局**：
| 品质 | 布局 |
|------|------|
| 普通 | 1行4格 |
| 优秀 | 1行6格 |
| 精良 | 2行4格 |
| 史诗 | 2行6格 |
| 传说 | 3行6格 |

**右侧 - 背包**：

- 背包物品网格（按稀有度排序）
- 物品图标：Disc=菱形、Program=三角
- 拖拽物品到面板外丢弃
- 排序按钮

## 四、游戏内元素

### 4.1 攻击方向指示器

- **位置**：跟随本地玩家
- **逻辑**：玩家中心 + 半径外的三角标记，跟随鼠标方向
- **样式**：青色三角，仅本地玩家可见

### 4.2 实体头顶血条

- **位置**：怪物头顶
- **内容**：血条
- **样式**：本地玩家不显示

## 五、风格要点

1. **无圆角**：保持锐利几何风格
2. **半透明**：面板背景 60-80% 透明度
3. **极简边框**：1px 深青灰色
4. **几何图形**：六边形=玩家、三角=怪物、菱形=Disc
5. **发光效果**：使用 HDR 高亮值触发 Bloom
